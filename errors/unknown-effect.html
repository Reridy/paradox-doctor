HOI4 ERROR GUIDE

Unknown effect, trigger or scope failure

The same-looking error can come from a typo, an unavailable command, the wrong script context, or a scope that changed earlier than expected.

Debug in this order

  1. Confirm the command name against a working example for the current game version.
  2. Check whether the command is valid as an effect, trigger or modifier in that location.
  3. Trace the current scope immediately before the reported line.
  4. Check scripted effects/triggers and dependencies if the command is custom.
  5. After a fix, reproduce once with a fresh log rather than reading stale messages.
