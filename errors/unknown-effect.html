HOI4 ERROR GUIDE

Unknown effect or trigger

This error means HOI4 does not recognize a script command in the place where it appears. The cause can be a typo, wrong scope, outdated syntax, or a missing dependency.

What to check

  1. Verify the command spelling exactly.
  2. Check whether the command is an effect, trigger, or value and is used in the correct context.
  3. Review the current scope. Some commands only work for countries, states, characters, units, or other specific scopes.
  4. If the command comes from another mod, confirm that dependency is enabled and loaded.
  5. Check whether a game update changed or removed the command.

Use error.log analysis

Upload error.log to Paradox Doctor and matching lines are grouped as unknown script commands with a short explanation.
