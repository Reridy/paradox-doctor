HOI4 LOCALIZATION GUIDE

HOI4 localization shows raw keys

If the game displays an identifier such as MY_FOCUS_NAME instead of readable text, the scripted object may exist while its localization entry is missing, malformed, overridden or not loaded.

Quick answer

Confirm the localization file is under the expected localization folder, has the correct language header, uses valid key:0 "Text" syntax, and is saved with the encoding your setup expects. Then search for duplicate definitions of the same key.

Check these in order

  1. Exact key match: the script reference and localization key must match character for character.
  2. Language header: the first active line should declare a language such as l_english:.
  3. Entry syntax: verify the colon, optional version number and quoted text.
  4. File placement: make sure the file is in the localization structure the game loads.
  5. Encoding: if valid-looking text still fails, verify the file encoding in your editor.
  6. Duplicates: another file may define the same key and make the result depend on load order.

Raw key vs missing game object

A raw localization key does not automatically mean the focus, event, idea or decision failed to load. Separate the object problem from the text problem: first confirm the object exists, then verify its localization.
