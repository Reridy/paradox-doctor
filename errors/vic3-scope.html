VICTORIA 3 ERROR GUIDE

Unset scope, wrong scope, invalid event target

Victoria 3's Jomini log often reports the point where a script can no longer resolve the object it expected. That line is the failure point, but the scope may have become invalid earlier.

Debug in this order

  1. Read the reported expected scope: country, state, character, interest group, etc.
  2. Identify what scope the surrounding block actually provides.
  3. Trace every scope change, saved scope and event target leading into the reported line.
  4. Check whether an object can legitimately be absent. A character, leader, target country or journal target may not exist in every situation.
  5. Add or correct validity checks only when they match real game syntax; do not invent a trigger because an AI assistant suggested one.
