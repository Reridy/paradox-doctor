HOI4 MAP GUIDE

State, province and strategic-region failures

Map changes often touch several files at once. A state can look correct in isolation while its province membership conflicts elsewhere.

High-signal checks

  • Every selected state has a unique state ID.
  • A province is not assigned to multiple selected states.
  • A province is not repeated across multiple selected strategic-region files.
  • New or split states have the expected category and history data.
  • Map changes are reproduced in debug mode with a fresh error.log.

A missing buildings block is not automatically an error, so Paradox Doctor reports it only as a low-confidence review item.
