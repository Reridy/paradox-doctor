VICTORIA 3 GUIDE

Journal entries and event references

Journal scripting becomes difficult when a reference comes from vanilla or another dependency. A missing ID in your own project is not automatically a broken reference.

What Paradox Doctor checks

  • Duplicate selected journal-entry keys
  • Duplicate selected event IDs
  • Journal-to-event references that are not found in the project
  • Optional lookup in a locally selected vanilla/dependency reference folder
  • Suspicious timeout = 0 usage as a heuristic, not a definite error

When a reference is absent and no dependency context is loaded, the finding stays low- or medium-confidence.
