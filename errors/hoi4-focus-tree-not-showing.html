HOI4 focus tree not showing

If your country still receives the generic focus tree—or your intended tree never becomes active—the problem is often in tree selection, structure or loading rather than the individual focuses themselves.

Quick answer

Confirm the file is being loaded, the top-level focus_tree block is valid, the tree has a unique ID, and the country-selection logic can actually select the intended country. Then check duplicate focus IDs and broken prerequisites.

Check the tree selector first

  • The focus_tree block must parse correctly.
  • The tree ID should be unique and stable.
  • Country-selection rules must match the target country or original tag as intended.
  • If several trees can match, their selection logic can compete.
  • A file in the wrong path or a malformed file may never load as expected.

Then check focus-level problems

  1. Look for duplicate focus IDs across selected files.
  2. Verify prerequisite references point to an existing focus in the active content set.
  3. Inspect brace balance around the first focus definitions.
  4. Check whether a parser error earlier in the file prevents the rest of the tree from loading.
  5. Use localization as a separate check: raw or missing text does not necessarily mean the focus object itself failed to load.

Generic tree vs broken custom tree

If the game cleanly falls back to the generic tree, selection logic is a strong suspect. If the UI is partially populated or the log reports focus parsing/reference errors, inspect the custom tree structure and IDs first.

What Paradox Doctor can check

  • Duplicate selected focus IDs
  • Supported prerequisite-reference heuristics
  • Brace imbalance and parser-related log messages
  • Focus localization/reference heuristics
  • Regression comparison when the tree worked in an earlier project version
