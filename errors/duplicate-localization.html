LOCALIZATION ERROR GUIDE

Duplicate localization found

A localization key should normally resolve to one intended definition in the active content set. Duplicate definitions make the result dependent on load order and replacement behavior.

Fix it safely

  1. Find every definition of the reported key.
  2. Decide whether the second definition is an accidental copy or an intentional override.
  3. Remove or rename accidental duplicates.
  4. If you are intentionally replacing vanilla/dependency text, keep the override structure explicit and documented.
  5. Rescan before launching so the duplicate does not get buried in the next log.

Paradox Doctor separates duplicates inside one file from duplicates spread across multiple selected files.
