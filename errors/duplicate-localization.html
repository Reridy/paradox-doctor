HOI4 ERROR GUIDE

Duplicate localization found

This error means the same localization key is defined more than once. The game can load one value over another, making text appear inconsistent and leaving the log noisy.

What to check

  1. Copy the key named after key: in error.log.
  2. Search every localization .yml file in the mod for that exact key.
  3. Keep the intended definition and rename or remove the duplicate.
  4. If both entries are supposed to exist, give them different keys and update their script references.

Why Paradox Doctor helps

The folder scanner builds a localization index across the selected mod and reports duplicate keys even when they are in different files.

Common causes

  • Copying a vanilla or another mod's localization file and keeping the original key.
  • Defining the same key in separate language files that are actually loaded as the same language.
  • Renaming a scripted object without cleaning up the old localization entry.
