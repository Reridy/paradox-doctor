VICTORIA 3 ERROR GUIDE

Localization shows raw keys

If the game displays identifiers such as building_example instead of readable text, the script object may exist while its localization is missing or not being loaded.

Checklist

  1. Verify the file is inside the mod's expected localization language-folder structure.
  2. Make the first non-comment line a language header such as l_english:.
  3. Use the normal key:0 "Text" structure and balanced quotes.
  4. Save as UTF-8 with BOM when the game refuses to load an otherwise-correct file.
  5. Check that the localization key exactly matches the identifier referenced by the script.
  6. When overriding game content, verify the folder and filename conventions expected by the current game version.

Why this is common

Community questions repeatedly trace missing Victoria 3 text back to file format, path or localization-key mistakes rather than the underlying game object.
