VICTORIA 3 GUIDE

Localization shows raw keys

If an identifier appears instead of readable text, the object may exist while its localization file is missing, malformed or not loaded from the expected path.

Checklist

  1. Verify the file is under the expected localization structure.
  2. Make the first non-comment line a language header such as l_english:.
  3. Check key:0 "Text" syntax and duplicate keys.
  4. If a valid-looking file still does not load, verify its UTF-8/BOM encoding in your editor.
  5. Confirm the key exactly matches the script reference.

Paradox Doctor reads the raw file bytes for BOM information instead of guessing from already-decoded text.
