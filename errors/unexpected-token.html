HOI4 ERROR GUIDE

Unexpected token

An unexpected token usually means the parser reached text that does not fit the structure it expected. The actual mistake can be on the reported line or several lines earlier.

Fast debugging checklist

  1. Check opening and closing braces around the reported block.
  2. Look for a missing =, quote, or closing brace before the error line.
  3. Temporarily remove or comment out the smallest suspicious block and reload the game.
  4. If the error moves, the malformed syntax is usually inside the block you changed.

Use the scanner

Paradox Doctor tracks simple brace balance in script files and classifies unexpected-token entries in error.log so you can narrow the search faster.

Common causes

  • One missing } causing the rest of the file to be parsed in the wrong scope.
  • A copied block with an extra token or missing equals sign.
  • Using syntax from a different game version or another Paradox title.
