HOI4 CRASH GUIDE

HOI4 mod crashes after adding a state

If Hearts of Iron IV reaches the country-selection screen but crashes after you start the campaign—and removing the new state makes the crash disappear—treat the state change as a cross-file map problem first.

Quick answer

Check province membership before chasing unrelated warnings. A new or split state can break because the same province is still assigned to the old state, a strategic-region definition no longer matches the map, the state block is malformed, or required state/map data was not carried over correctly.

Typical symptoms

  • The game loads to the menu or country-selection map.
  • Starting a country causes a CTD during campaign loading.
  • Removing the new state files restores normal loading.
  • error.log contains many warnings that do not obviously explain the crash.
  • The map may appear correct in Nudge or debug mode even though another file still references the old province layout.

Check these causes first

  1. Province overlap: make sure no province is assigned to both the old state and the new state.
  2. Strategic-region membership: confirm the affected provinces are not duplicated across selected strategic-region files.
  3. State structure: verify braces, the state ID, province list, category and history block.
  4. State data carried over during a split: review state-level values and map-related data you expected to preserve, including buildings data when your setup requires it.
  5. Stale generated files: if you used Nudge, confirm generated map/history files were moved into the mod deliberately and that stale files are not being loaded from the user directory.

Fast isolation workflow

  1. Reproduce the crash once and keep a fresh error.log.
  2. Temporarily test only the target mod and required dependencies.
  3. Compare the old and new state province lists side by side.
  4. Check the same provinces in strategic regions.
  5. Fix the first structural or membership problem you can prove, relaunch once, and generate a new log.

Do not try to fix every warning in the log at once. Many engine messages are unrelated or are consequences of an earlier map failure.

What Paradox Doctor can check

  • Duplicate selected state IDs
  • Provinces assigned to multiple selected states
  • Duplicate selected strategic-region province membership
  • Brace imbalance and common state/map log patterns
  • Regression comparison between a working project and the broken version

It cannot prove the entire HOI4 map is valid from a partial folder. A clean scan means only that the supplied files did not trigger a supported rule.
