ROADMAP

Diagnosis stays useful before monetization matters.

Paradox Doctor is still a beta. There is no paid plan to buy today. Future paid features should save substantial debugging time rather than lock basic error explanations behind a paywall.

Already in the free beta

  • HOI4 and Victoria 3 project + error.log diagnosis
  • Root-cause prioritization and repeated-log grouping
  • Local regression baselines and ignored findings
  • Optional local vanilla/dependency reference comparison
  • Markdown and JSON reports

Strong future candidates

  • Project snapshot comparison: what changed between the last working build and the broken build
  • Two-mod compatibility comparison for IDs, overrides and replace paths
  • Game-version-aware validation packs
  • Safe fix suggestions with a visible diff before any change
  • Team-oriented reports and project history

These are candidates, not promises. Real modder cases and false-positive data should decide priority.
