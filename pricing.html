ROADMAP

Ship useful debugging tools before charging for them.

Paradox Doctor v1 is free. There is no paid plan today. Future paid functionality should save substantial debugging time instead of withholding basic diagnosis.

Available in v1

  • HOI4 and Victoria 3 project + error.log diagnosis
  • Root-cause prioritization and repeated-log grouping
  • Local baseline comparison and ignored findings
  • Project Regression Doctor for working-vs-broken folder comparison
  • Mod Compatibility Doctor for two-mod conflicts
  • Optional vanilla/dependency reference comparison
  • Markdown and JSON reports

Future candidates

  • Game-version-aware validation packs
  • Safer fix suggestions with a visible before/after diff
  • Deeper reference graphs and dependency-aware analysis
  • CI-friendly machine-readable regression thresholds
  • Team-oriented project history if real teams request it

These are candidates, not promises. Real false-positive and missed-diagnosis reports should decide priority.
