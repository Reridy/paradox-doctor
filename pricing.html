SUSTAINABLE PRODUCT ROADMAP

Keep diagnosis free. Charge only for real time savings.

There is no paid plan available yet. The purpose of this page is to make the product direction clear before asking anyone to pay.

Free — current direction

  • HOI4 and Victoria 3 game-specific diagnostic profiles
  • Project-folder and error.log scanning
  • Cross-file duplicate and localization checks
  • Root-cause prioritization and repeated-log collapsing
  • Game-specific troubleshooting guides
  • Markdown and JSON report export
  • Local-only scan history metadata

Future Pro candidates

  • Safe fix workspace: proposed fixes with before/after diff and explicit confirmation
  • Project snapshots: compare two mod versions to identify which change introduced a failure
  • Compatibility inspector: compare overlapping files and identifiers between multiple mods
  • Game-version rules: deeper validation tied to specific HOI4/Victoria 3 versions
  • Advanced reference graph: track where IDs, scripted effects, localization keys and targets are defined and used
  • Team reports: shareable diagnostics designed for mod teams and issue templates

These are plans, not promises. Features should only become paid when they are reliable enough to save meaningful time.

Help decide what gets built

The fastest way to validate demand is real modder feedback. Open an issue with the game, the error you hit, and what you wish a tool could have done automatically.
