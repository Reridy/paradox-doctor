ABOUT

A practical diagnostic assistant, not a replacement for the game engine.

Paradox Doctor is built for fast browser-based triage. It prioritizes reproducible structural checks and clearly labels heuristic findings.

Hearts of Iron IV

  • Project + error.log triage
  • Brace structure and localization format
  • Duplicate focus, event and state IDs
  • State/province and strategic-region duplicate membership
  • Focus-reference and localization heuristics
  • Regression and two-mod compatibility comparison

Victoria 3

  • Project + error.log triage
  • Localization path/format checks
  • Journal, event and state-region duplicate IDs
  • Scope/event-target log grouping
  • Journal/event reference heuristics
  • Regression and two-mod compatibility comparison

What a clean scan means

Only that no supported rule found a problem in the supplied context. Paradox Doctor is not a complete Clausewitz/Jomini parser and cannot prove a mod is valid. Use the game's debug output, map validation, and specialized validators when needed.

Browser limits

Large selections are intentionally capped to keep the browser responsive. Folder selection is the preferred workflow; individual-file selection remains available as a fallback. All current analysis is local to the page.
