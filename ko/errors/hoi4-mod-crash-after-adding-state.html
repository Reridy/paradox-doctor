HOI4 크래시 가이드

호이4에서 state를 추가한 뒤 크래시할 때

Hearts of Iron IV가 국가 선택 화면까지는 정상적으로 들어가지만 캠페인을 시작한 뒤 크래시하고, 새 state를 제거하면 다시 정상 작동한다면 먼저 여러 파일에 걸친 지도 데이터 문제로 보는 것이 좋습니다.

빠른 답

관련 없는 경고를 쫓기 전에 province 소속부터 확인하세요. 새 state 또는 분리한 state는 같은 province가 기존 state에도 남아 있거나, strategic region 정의가 새 지도와 맞지 않거나, state 블록 구조가 깨졌거나, 분리 과정에서 필요한 state/map 데이터가 제대로 옮겨지지 않아 문제가 생길 수 있습니다.

전형적인 증상

  • 메뉴 또는 국가 선택 지도까지는 로드됩니다.
  • 국가를 시작하면 캠페인 로딩 중 CTD가 발생합니다.
  • 새 state 파일을 제거하면 정상적으로 로드됩니다.
  • error.log에 크래시 원인처럼 보이지 않는 경고가 많이 나타납니다.
  • Nudge나 debug mode에서는 지도가 정상처럼 보여도 다른 파일이 옛 province 구성을 계속 참조할 수 있습니다.

이 원인부터 확인

  1. Province 중복: 하나의 province가 기존 state와 새 state에 동시에 들어가 있지 않은지 확인합니다.
  2. Strategic region 소속: 영향을 받은 province가 선택한 strategic-region 파일 사이에서 중복되지 않는지 확인합니다.
  3. State 구조: 중괄호, state ID, province 목록, category와 history 블록을 확인합니다.
  4. 분리 과정에서 옮겨야 할 state 데이터: buildings 데이터를 포함해 유지하려 했던 state 단위 값과 지도 관련 데이터를 다시 확인합니다.
  5. 오래된 생성 파일: Nudge를 사용했다면 생성된 map/history 파일을 의도적으로 모드로 옮겼는지, 사용자 폴더에 남은 오래된 파일이 같이 로드되고 있지 않은지 확인합니다.

빠르게 원인 격리하기

  1. 크래시를 한 번 재현하고 최신 error.log를 보관합니다.
  2. 문제 모드와 반드시 필요한 의존성만 켜고 테스트합니다.
  3. 기존 state와 새 state의 province 목록을 나란히 비교합니다.
  4. 같은 province를 strategic region에서도 확인합니다.
  5. 확실히 증명할 수 있는 첫 구조/소속 문제 하나만 수정하고 다시 실행해 새 로그를 만듭니다.

로그에 있는 모든 경고를 한꺼번에 고치려 하지 마세요. 많은 엔진 메시지는 무관하거나 앞쪽 지도 오류의 결과일 수 있습니다.

Paradox Doctor가 확인할 수 있는 것

  • 선택한 파일의 중복 state ID
  • 여러 state에 동시에 들어간 province
  • 선택된 strategic region 사이의 중복 province 소속
  • 중괄호 불균형과 흔한 state/map 로그 패턴
  • 정상 프로젝트와 깨진 버전 사이의 회귀 비교

일부 파일만으로 HOI4 지도 전체가 유효하다는 것을 증명할 수는 없습니다. 깨끗한 검사 결과는 제공한 파일이 현재 지원되는 규칙에 걸리지 않았다는 뜻입니다.
