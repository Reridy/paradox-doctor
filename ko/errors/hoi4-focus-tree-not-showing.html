HOI4 국가중점 가이드

호이4 국가중점이 안 뜰 때

커스텀 국가가 계속 기본 중점 트리를 받거나, 만든 중점 트리가 전혀 활성화되지 않는다면 개별 focus 내용보다 먼저 트리 선택 조건, 구조, 파일 로딩을 확인하는 것이 좋습니다.

빠른 답

파일이 실제로 로드되는지, 최상위 focus_tree 블록이 유효한지, 트리 ID가 고유한지, 국가 선택 조건이 목표 국가를 실제로 선택할 수 있는지 확인하세요. 그 다음 중복 focus ID와 잘못된 prerequisite를 확인합니다.

트리 선택 조건부터 확인

  • focus_tree 블록이 정상적으로 파싱되어야 합니다.
  • 트리 ID는 고유하고 안정적으로 유지하는 것이 좋습니다.
  • 국가 선택 조건이 의도한 국가 또는 original tag와 실제로 일치해야 합니다.
  • 여러 트리가 동시에 조건을 만족하면 선택 로직이 서로 경쟁할 수 있습니다.
  • 파일 경로가 잘못됐거나 파일 구조가 깨졌다면 예상대로 로드되지 않을 수 있습니다.

그 다음 focus 단위 문제 확인

  1. 선택한 파일들 사이에 중복 focus ID가 있는지 확인합니다.
  2. prerequisite가 현재 로드된 콘텐츠에 실제로 존재하는 focus를 참조하는지 확인합니다.
  3. 첫 focus 정의 주변의 중괄호 균형을 점검합니다.
  4. 파일 앞쪽의 parser 오류 때문에 뒤쪽 focus가 로드되지 않는지 확인합니다.
  5. 현지화 문제는 따로 봅니다. 텍스트가 raw key로 보인다고 focus 오브젝트 자체가 로드되지 않은 것은 아닙니다.

기본 중점 트리인가, 깨진 커스텀 트리인가?

게임이 깔끔하게 기본 중점 트리로 돌아간다면 선택 조건을 우선 의심할 만합니다. 반대로 UI 일부만 나오거나 로그에 focus 파싱/참조 오류가 보인다면 커스텀 트리 구조와 ID부터 확인하세요.

Paradox Doctor가 확인할 수 있는 것

  • 선택된 파일의 중복 focus ID
  • 지원되는 prerequisite 참조 추정 검사
  • 중괄호 불균형과 parser 관련 로그 메시지
  • focus 현지화/참조 관련 추정 검사
  • 예전에는 작동했던 프로젝트 버전과의 회귀 비교
focus 파일 검사정상 버전과 비교
