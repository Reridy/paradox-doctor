PRIVACY

Your mod files stay in the browser.

The public beta is a static GitHub Pages application. It does not have an application backend that receives the project folders, reference folders or error.log text you select.

Processed locally

  • Selected mod files and folders
  • Selected vanilla/dependency reference folders
  • Uploaded or pasted error.log text
  • Imported diagnostic JSON reports

Stored locally on your device

  • Your selected game preference
  • Saved regression baseline fingerprints
  • Ignored-finding fingerprints

Fingerprints describe a finding pattern; they do not contain the source file contents. Clearing site storage in your browser removes these local preferences.

Reports you export

Markdown and JSON reports contain diagnostic metadata and findings, including reported file paths and explanations. They do not include the full source files. Review a report before posting it publicly if your local path names contain information you do not want to share.
