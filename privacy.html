PRIVACY

Local-first by design

The current Paradox Doctor scanner is a static browser application hosted on GitHub Pages. Selected mod files and pasted error.log contents are processed by JavaScript in your browser.

What is not uploaded by this version

  • Selected HOI4 or Victoria 3 mod file contents
  • Selected folder contents
  • Pasted or uploaded error.log contents
  • Exported diagnostic reports

What can be stored locally

If you choose a game, the site can remember that game choice in browser localStorage. Recent diagnosis history stores only summary metadata such as game, timestamp, score, and error counts. It does not store the mod source text itself. You can clear recent history from the site, or clear browser site data.

External links

Links to GitHub or other external sites leave Paradox Doctor and are governed by those services' privacy practices. Future analytics, accounts, payments, or server-side features would require this page to be updated before being enabled.

Important note

Because this is a community diagnostic tool, do not rely on a clean scan as proof that a mod is safe or error-free. Keep backups before making changes to a mod project.
