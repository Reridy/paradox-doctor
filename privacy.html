PRIVACY

Your mod files stay in the browser.

The current public version is a static GitHub Pages application. Paradox Doctor has no application backend receiving the project folders, comparison folders, reference folders or error.log text you select.

Processed locally

  • Selected mod files and folders
  • Regression working/broken project folders
  • Two-mod compatibility comparison folders
  • Selected vanilla/dependency reference folders
  • Uploaded or pasted error.log text
  • Imported diagnostic JSON reports

These files are read by JavaScript running in your browser for the requested analysis. Paradox Doctor does not intentionally transmit their contents to an application server.

Stored locally on your device

  • Your selected game preference
  • Saved regression baseline fingerprints
  • Ignored-finding fingerprints

Fingerprints describe a finding pattern; they do not contain source-file contents. Clearing this site's browser storage removes those preferences.

Reports you export

Markdown and JSON reports contain diagnostic metadata, reported file paths and explanations. They do not include full source files. Review a report before posting it publicly if your file paths or mod names contain information you do not want to share.

Hosting and access logs

This site is hosted using GitHub Pages. Although Paradox Doctor itself does not run an application backend for your mod files, the hosting provider may process ordinary connection information such as IP addresses, request metadata, security logs, or similar technical data under GitHub's own privacy and security practices.

External links

Opening GitHub or another external destination leaves this site and is subject to that service's own terms and privacy practices. Paradox Doctor currently embeds no advertising network or third-party analytics script.

Future changes

If Paradox Doctor later adds accounts, analytics, advertising, cloud project storage, payments, or any feature that sends diagnostic content to a server, this privacy notice should be updated before that feature is publicly enabled.
