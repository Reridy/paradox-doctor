Debug HOI4 mods without reading the same log line 200 times.

Paradox Doctor combines project checks with a fresh error.log and puts high-confidence structural problems before lower-confidence heuristics.

  • Duplicate focus IDs, event IDs and unresolved focus prerequisites
  • Duplicate state IDs and provinces assigned to multiple selected states
  • Duplicate province membership across selected strategic-region files
  • Common map/state, effect, scope and missing-reference log patterns
  • Optional descriptor version and local reference-folder comparison

Some checks are intentionally marked as heuristics when vanilla or dependency context may explain the finding.
